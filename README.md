# StaySafe Online

<p align="center">
    <img src="images/logo.png" alt="StaySafe Online Logo" width="120" />

**StaySafe Online** helps people browse the internet more safely and confidently through practical resources, security tips, threat explanations, and useful tools.

---

## Live Demo

[Try StaySafe Online](https://anandksri.github.io/staysafe-online)

---

## Key Features

- **Learn**: Easy-to-understand guides on online safety
- **Tips**: Practical security habits for safer browsing
- **Threats Explained**: Clear breakdowns of common cyber risks
- **Toolbox**: Curated cybersecurity tools and resources
- **News & Alerts**: Cybersecurity updates and awareness content
- **Responsive Design**: Works across desktop and mobile devices
- **SEO Support**: Meta tags, Open Graph, and structured data
- **Accessibility**: ARIA roles and keyboard-friendly navigation
- **PWA Support**: Web manifest and installable-app support

## Get Started

No build system is required for the current version.

Clone the repository:

```bash
git clone https://github.com/anandksri/staysafe-online.git
cd staysafe-online
```

Open `index.html` directly, use VS Code Live Server, or serve the directory with a local HTTP server.
